# DroneTV AI Support & Lead Assistant

A responsive Full-Stack web application featuring an AI support chatbot, customer/student enquiry collection form, and an admin dashboard for enquiry management.

##  Tech Stack
- **Frontend:** React.js, TypeScript, HTML5, CSS3 / Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** Neon PostgreSQL
- **Version Control:** Git & GitHub

##  Key Features
- **Responsive Landing Page:** DroneTV services, training courses, and overview.
- **Rule-Based Support Chatbot:** Predefined Q&A handling user queries with quick prompts.
- **Enquiry Collection Form:** Input validation for student/customer lead generation.
- **Admin Dashboard:** View, search, filter (Student/Customer), and update enquiry statuses (`New`, `Contacted`, `In Progress`, `Closed`).
- **RESTful API:** Full CRUD operations on PostgreSQL.
